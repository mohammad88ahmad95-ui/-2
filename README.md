# حساباتي — Hasabati

تطبيق أندرويد لإدارة حسابات وطلبات تجارة الوساطة (عميلات ↔ وكيلة SHEIN) — بالعربية بالكامل، RTL، بدون إنترنت.

## ⚠️ مهم قبل البدء

هذا المشروع **كود مصدري كامل وحقيقي** (لا نماذج شكلية) لكنه لم يُبنَ إلى ملف APK هنا، لأن بيئة العمل التي أنشأته لا تملك اتصال إنترنت، وبناء أي تطبيق أندرويد يتطلب تحميل Android SDK وGradle والمكتبات من الإنترنت. لبناء APK فعلي:

1. ثبّتي **Android Studio** (مجاني من developer.android.com).
2. افتحي هذا المجلد (`hasabati/`) كمشروع Android Studio: File → Open.
3. اتركي Android Studio يُنزّل Gradle والمكتبات تلقائياً (يحتاج إنترنت في هذه الخطوة فقط، مرة واحدة).
4. اضغطي Run ▶ لتشغيله على هاتف حقيقي متصل بسلك USB (مع تفعيل "خيارات المطور" و"تصحيح USB")، أو على محاكي Android.
5. لإنتاج ملف APK قابل للتثبيت: Build → Build Bundle(s) / APK(s) → Build APK(s).

## ما الذي تم بناؤه فعلياً (وليس شكلياً)

- **قاعدة بيانات Room كاملة**: Customer، Order، OrderItem، وTransaction (سجل مالي موحّد — كل حركة مالية عملية مستقلة في هذا الجدول).
- **FinanceEngine.kt**: كل القواعد المحاسبية من الطلب الأصلي مطبّقة كدوال حسابية صرفة (لا أرقام شكلية):
  - الخزينة: Cash USD / Cash SYP / Sham Cash USD / Sham Cash SYP — منفصلة تماماً، بدون تحويل تلقائي بين العملتين.
  - مستحقات العملاء، والمستحق للوكيلة (لا يُحتسب دين على الوكيلة إلا بعد تأكيد وصول الطلب وتكلفته الفعلية).
  - رأس المال (ابتدائي + إضافات − سحوبات شخصية) منفصل تماماً عن الأرباح.
  - الربح المتوقع مقابل الربح الفعلي/المحقق.
- **HasabatiRepository.kt**: نقطة الدخول الوحيدة لكل شاشة — تطبّق كل قاعدة من قسم "قواعد المحاسبة" في الطلب الأصلي (العربون ليس ربحاً، التصحيح بعملية عكسية بدل الحذف، إلخ).
- **الشاشات (Jetpack Compose + Material 3)**:
  - لوحة التحكم: أرصدة، إجراءات سريعة، "يحتاج متابعة"، آخر الحركات.
  - الطلبات: قائمة + بحث + فلاتر، إنشاء طلب متعدد المنتجات مع عربون اختياري، تفاصيل الطلب (تأكيد الوصول بالتكلفة الفعلية لكل منتج، تغيير الحالة، تحصيل دفعة، إلغاء مع منطق الاسترداد).
  - العملاء: قائمة + كشف حساب زمني لكل عميلة.
  - الخزينة: الأرصدة الأربعة + سجل الحركات.
  - حساب الوكيلة: المستحق/المدفوع/المتبقي + سجل الدفعات + زر دفع للوكيلة.
  - المصاريف: تسجيل بفئات (مواصلات، تغليف، إلخ).
  - التقارير: حسب الفترة (اليوم/الأسبوع/الشهر/الكل).
  - الإعدادات: رأس المال (إضافة/سحب شخصي)، نسخ احتياطي (تصدير/استيراد JSON كامل)، قفل PIN اختياري.
- **RTL كامل** مفروض برمجياً، وهوية بصرية كحلي/بنفسجي/أبيض/رمادي كما طُلب.

## ما لم يُستكمل أو يحتاج مراجعة قبل الاعتماد عليه فعلياً

بصراحة تامة، ولضخامة الطلب الأصلي (45 قسماً)، هذه النقاط تحتاج انتباهك أو تطويراً إضافياً قبل الاعتماد الكامل على التطبيق في عملك:

- **لم أُشغّل مُصرّف Kotlin فعلياً على هذا الكود** (لا توجد إمكانية بناء أندرويد في بيئتي) — من المتوقع وجود أخطاء صغيرة في الاستيراد (imports) أو التوافق قد تظهر أول مرة تفتحين المشروع في Android Studio. Android Studio سيُظهرها لك بوضوح بالأحمر، وهي عادة تُصلح بضغطة زر واحدة (Alt+Enter → "Import").
- **لم أكتب اختبارات آلية (Unit Tests)** لسيناريوهات القسم 41 — رغم أن منطق FinanceEngine مصمم ليكون قابلاً للاختبار بسهولة (دوال صرفة بدون قاعدة بيانات).
- **البيانات التجريبية الاختيارية** (القسم 32/45) غير مُضافة — يمكن إضافتها لاحقاً كدالة seed بسيطة.
- **تشفير ملف النسخة الاحتياطية** غير مُفعّل — الملف JSON نصي عادي حالياً؛ يمكن إضافة تشفير AES بسيط لاحقاً.
- **معرّف الوكيلة (Agent)** غير منفصل ككيان مستقل في قاعدة البيانات لأنك ذكرتِ وكيلة واحدة فقط — إن احتجتِ لاحقاً أكثر من وكيلة، ستحتاجين جدول Agent منفصل وربط كل Order وAgentTransaction به.
- شاشة قفل الـ PIN بسيطة (بدون بصمة) — الطلب الأصلي ذكر البصمة كخيار لاحق فقط، وهذا متوافق مع ذلك.

## البنية

```
hasabati/
├── app/src/main/java/com/hasabati/app/
│   ├── data/db/          Room: entities, DAOs, Database, Converters
│   ├── data/repository/  HasabatiRepository (كل المنطق التجاري) + BackupManager
│   ├── domain/           FinanceEngine (المحرك المحاسبي الصرف — قابل للاختبار)
│   ├── ui/<feature>/     كل ميزة: ViewModel + Screen (Compose)
│   ├── MainActivity.kt
│   └── HasabatiApplication.kt (حقن تبعيات يدوي بسيط)
```

**التقنيات**: Kotlin، Jetpack Compose، Material 3، Room، MVVM يدوي (بدون Hilt لتبسيط الإعداد)، Navigation Compose، DataStore (لإعداد PIN)، Offline بالكامل.

**Package name**: `com.hasabati.app`
